# Workflows n8n & Site de niche

Ce dépôt contient des exemples de workflows n8n et un squelette de site statique pour la niche **Blanchiment Dentaire Paris 2025**.

## Structure

- `automatisations-ia/` : exemples de workflows n8n au format JSON.
- `site/` : mini site HTML avec plusieurs pages (prix, comparatif, praticiens, pages locales).

## Lancer le projet

1. Importer les fichiers JSON dans n8n si vous souhaitez utiliser les automatisations fournies.
2. Déployer le contenu du dossier `site/` sur n'importe quel hébergeur (GitHub Pages, Netlify, etc.).

Ce squelette est volontairement minimal : complétez les pages avec le contenu expert décrit dans l'analyse SEO et intégrez vos propres workflows n8n.
